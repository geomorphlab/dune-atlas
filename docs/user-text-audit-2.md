# User-text audit 2 (PI rules, October 2026)

Second audit of the user-facing text of both atlases (layer list, info buttons, captions, tables, Help, tour,
About, export/download README and metadata strings, citation labels, NetCDF/CSV attributes, PNG export
strips), after the PI-edited physics text (`earth-physics-text_AG.md`) was applied. Rules:

* **a** descriptions stay on topic and definitional; non-definitional asides are cut unless needed for correct use;
* **b** no text that only holds for the present wind datasets: general text does not enumerate the datasets or
  their grids / periods; dataset facts come from the dataset table (registry `datasets` entries and
  `app/src/cell/datasetinfo.ts`, Mars `app/src/mars/cell/datasetinfo.ts`) or are given as examples ("e.g., …");
* **c** attribution: "methods outlined in Gunn (2026)" or the original source for methods the PI used but did not
  devise; "following Gunn (2026), Methods M6" for his own implementation.

PI text items are applied verbatim (only "reviewd" -> "reviewed" and markup adapted). Commit `4b8a690` (branch
`mars`) unless noted. "Both" = Earth and Mars builds.

## 3. Checked and left unchanged

* Dataset facts inside dataset-specific places (the dataset table, the per-dataset citation entries in
  `app/src/cell/citation.ts`, the dataset option labels and tooltips, the land and dune rules per dataset, the
  per-dataset README / metadata lines) — allowed by rule b.
* "following Gunn (2026), Methods M6" (divergence: About, info, table note, downloads) and "(Gunn 2026, Methods
  M3)" (Earth sand-flux) — his implementation, allowed by rule c.
* Vegetation's "0.1°" (the vegetation product's own grid, not a wind dataset), aridity's native 30″ grid.
* Earth divergence "undefined at coasts" in the download metadata (`app/src/cell/auxinfo.ts`): needed to read the
  empty values (rule a).
* Tour steps 1–6 and 8, Help "Threshold", "Layers", "Clicking a cell", "Downloads", "Sharing": no dataset or
  attribution issue.

## 4. Unsure — not changed, for the PI

1. **PI text that names the present datasets** (kept verbatim as instructed, but it conflicts with rule b if a
   dataset is added): threshold ⓘ, 3rd paragraph ("Baas (2026) reports ERA5-Land 10 m wind speeds 20–30 % below
   those of ERA5, so the same threshold can give different results with the two wind datasets."); Wind dataset
   ⓘ / Help (3.16: "… for 1950–2024. ERA5-Land, used by Gunn (2026), … the two datasets … the same for both.").
   The About sand-flux and divergence items render the period and grids from the dataset table, so they follow
   the datasets automatically.
2. **Mars divergence ⓘ (PI text 3.14)**: applied with "the Mars sphere" but WITHOUT its last sentence ("No data at
   coasts (a neighbouring cell has no wind data) and on the ±90° rows."), which is not true on Mars (no land mask;
   every cell has a value, one-sided differences at the ±89° rows). This is the one deviation from the verbatim
   text; please confirm. The same text keeps "on rock, crusted or vegetated surfaces" on Mars.
3. **Dunes group description (Earth)**: "Global aeolian dune map on the 0.1° ERA5-Land grid (106,540 cells, 7.8 %
   of land area)." names ERA5-Land, but as the dune map's own grid, not as a wind dataset.
4. **Earth map attribution** "Dune and wind-regime data: Gunn (2026), CC BY 4.0": with ERA5 selected the
   wind-regime fields are computed by the atlas (Copernicus licence), not Gunn (2026) data.
5. **"migration mode" in other titles**: αH is now "Crest orientation, bed-instability mode"; the crest-flux titles
   still say "…, migration mode" (e.g. "Net across-crest flux, migration mode ⟨Q⊥(αH)⟩") and qhbf's definition
   "bed-mode (migration-mode, αH)". Rename to "bed-instability mode" for consistency?
6. **Dataset credit lines in code**: the export-strip wind credit (`windSourceText`, per dataset id) and the
